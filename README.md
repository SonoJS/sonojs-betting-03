# Betting Template 03 — Noxa

Catalogue casino lobby with **sticky top category tabs**, always-on header search, compact promo ticker, and wide landscape game tiles.

Frontend-only Noxa prototype (no backend, guest demo state).

## Run

```bash
# from monorepo root
npm install
npm run dev -w betting-03
```

Dev server: [http://localhost:4013](http://localhost:4013)

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Base UI · React Router
